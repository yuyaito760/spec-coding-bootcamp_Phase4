# 要件定義: DevDocs Agent

## 概要

開発者がライブラリ・フレームワークのドキュメントをチャットで質問すると、AIがContext7・Web検索・直接回答を自律的に選択して最新かつ正確な情報を返すエージェントアプリケーション。

---

## ユーザーストーリー

### 1. チャットで質問する

**ユーザーとして**、テキストを入力して送信するだけでAIに質問したい。  
**なぜなら**、ドキュメントサイトを探し回らずに必要な情報を素早く得たいから。

#### 受け入れ条件

- [ ] ユーザーがメッセージを入力して送信したとき、AIへのリクエストが開始される
- [ ] AIが応答を返したとき、メッセージ一覧に追加表示される
- [ ] 送信後、入力フォームがクリアされる
- [ ] Enterキーを押したとき、メッセージが送信される

---

### 2. AIルーターによるツール選択

**ユーザーとして**、AIが質問内容を判断して最適な情報源を自動選択してほしい。  
**なぜなら**、検索方法を意識せずに正確な情報を得たいから。

#### 受け入れ条件

- [ ] ライブラリ・フレームワークに関する質問のとき、まずContext7でドキュメントを検索する
- [ ] Context7で十分な情報が得られないとき、Tavily Web検索にフォールバックする
- [ ] Web検索でも情報が不足するとき、AIが直接回答する
- [ ] ツールを呼び出したとき、レスポンスにどのツールを使ったか情報が含まれる

---

### 3. 処理中のプログレス表示

**ユーザーとして**、AIが処理している間、進捗状況をリアルタイムで確認したい。  
**なぜなら**、応答を待っている間も処理が進んでいることを確認したいから。

#### 受け入れ条件

- [ ] リクエスト送信後、ローディングインジケーターが表示される
- [ ] Context7を検索中、「ドキュメントを検索中...」等のステータスが表示される
- [ ] Web検索中、「Web検索中...」等のステータスが表示される
- [ ] 応答が完了したとき、ローディング表示が消える
- [ ] ストリーミングで応答が届くとき、テキストがリアルタイムで表示される

---

### 4. ダークモード対応

**ユーザーとして**、ダークモードとライトモードを切り替えられるようにしたい。  
**なぜなら**、使用環境や好みに合わせた画面で作業したいから。

#### 受け入れ条件

- [ ] OSのダークモード設定がオンのとき、初期状態でダークモードが適用される
- [ ] ダークモード切り替えボタンを押したとき、テーマが即座に切り替わる
- [ ] テーマを切り替えたとき、チャット画面全体（背景・テキスト・コンポーネント）に適用される

---

## 非機能要件

### パフォーマンス
- Context7またはWeb検索のレスポンスはストリーミングで順次表示する
- 初回メッセージ表示まで体感的な遅延を最小化する

### セキュリティ
- APIキー（`GOOGLE_GENERATIVE_AI_API_KEY`, `TAVILY_API_KEY`）はサーバーサイドのみで使用し、クライアントに露出させない

### アクセシビリティ
- キーボードのみで操作可能（送信・入力）

---

## 今回の対象外

- チャット履歴の永続化（DBへの保存）
- ユーザー認証・ログイン機能
- テスト（E2E / Evals）※後から追加予定
